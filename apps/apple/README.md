# apps/apple

`PWMKit`, the Swift package shared by the iOS app, its AutoFill extension and the macOS app (D41). Run `just apple` on a Mac first: it builds the core into `PWMKit/Generated/` (gitignored).

| Target | What |
| --- | --- |
| `PWMCore` | The UniFFI Swift file over `pwm_ffiFFI.xcframework`, generated and never edited |
| `PWMKit` | `Session` (sign-up, login, unlock, sync, items), `Item`, `PWMError`, `Redacted`, `Generator`, `KeyStore` (Keychain), `CacheLocation` |
| `PWMDesign` | Design tokens (`Tokens.swift`, generated by `just tokens`) and their SwiftUI values |

Apps import `PWMKit` and `PWMDesign` only, never `PWMCore`.

**Secrets:** keep passwords, the Secret Key and revealed fields in locals or `Redacted`, and never log them. `os.Logger` calls take codes and counts only. See `docs/DEVELOPMENT.md` for building and testing on a Mac or Linux.
