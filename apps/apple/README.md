# apps/apple

The iOS app and `PWMKit`, the Swift package it shares with its AutoFill extension and the macOS app (D41, D42). On a Mac, run `brew install xcodegen` and then `just apple`. It builds the core into `PWMKit/Generated/` and generates `PWM.xcodeproj` from `project.yml`. Both are gitignored.

| Path | What |
| --- | --- |
| `project.yml` | The Xcode project (XcodeGen): the `PWM` app and its UI tests. Ids are placeholders until D1 |
| `App/` | The app shell: `PWMApp`, `Info.plist`, assets, the String Catalog |
| `UITests/` | Onboarding and the vault against a real server (`TEST_RUNNER_PWM_TEST_SERVER`) |
| `Config/` | Signing: `App.xcconfig`, and your team id in `Local.xcconfig` (gitignored) |
| `PWMKit/Sources/PWMCore` | The UniFFI Swift file over `pwm_ffiFFI.xcframework`, generated and never edited |
| `PWMKit/Sources/PWMKit` | `Session` (sign-up, login, unlock, sync, items, sign-out, the Emergency Kit), `Item`, `PWMError`, `Redacted`, `Generator`, `KeyStore` (Keychain), `CacheLocation` |
| `PWMKit/Sources/PWMDesign` | Design tokens (`Tokens.swift`, generated by `just tokens`) and their SwiftUI values |
| `PWMKit/Sources/PWMUI` | The screens: view models (tested on Linux too) and SwiftUI views, shared with the macOS app (M5.6) |

Apps import `PWMKit`, `PWMDesign` and `PWMUI` only, never `PWMCore`.

**Secrets:** keep passwords, the Secret Key and revealed fields in locals or `Redacted`, and never log them. View models clear them once they are sent to the core. `os.Logger` calls take codes and counts only. See `docs/DEVELOPMENT.md` for building and testing on a Mac or Linux.
